# Hardware image sources

`rc-controls.png` is copied without modification from
[nilskiefer/SVEA-PX4-Autopilot, revision 8e17861](https://github.com/nilskiefer/SVEA-PX4-Autopilot/blob/8e17861fa85809fecdbdddea035b0fa49264517a/docs/en/svea/pmb3/rc-controls.png).
It shows the transmitter used by that firmware's RC control guide.
The repository license is reproduced below.

The vehicle photograph used on the hardware page is the existing
`docs/media/svea_headshot.jpg` from this SVEA repository. Its caption identifies
the chassis, sensors and computer platform.

`esc-xl5.png` was supplied by the user for the RC startup guide. It shows
the Traxxas XL-5 ESC and its EZ-Set button.
