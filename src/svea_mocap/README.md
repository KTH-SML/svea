# svea_mocap

SVEA launch wrapper for the ROS 2 Qualisys driver from
[DISCOWER/motion_capture_system](https://github.com/DISCOWER/motion_capture_system).
The workspace base image installs the external driver.

See [MoCap localization](../../docs/mocap_localization.md) for QTM setup,
launch commands, map alignment, topic names and controller integration.
